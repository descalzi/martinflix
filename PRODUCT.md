# Product: MartinFlix

MartinFlix is a personal media system and its control room. The primary user is the administrator at home, checking whether services are working, finding problems and eventually managing backups and services. Household members may later browse and request media with fewer permissions. The first surface is a local, read-only operating console; it must clearly distinguish implemented capabilities from plans. The source of truth for visual guidance is the sibling uiux design library, applied in DESIGN.md. The MartinFlix masthead and mark in web/assets are the real brand assets. The public setup wizard on GitHub Pages lets anyone install, update, or reset a stack. Every step has a default and can be customised.
