# First-run installer

Start with a Linux host and an account that can run Docker Engine and Docker Compose. The installer uses Python 3.10+ and its standard library. If Docker is missing, install [Docker Engine and the Compose plugin](https://docs.docker.com/engine/install/) for your distribution and confirm `docker info` works as your normal user.

From the checkout, run:

```sh
python3 deploy/bootstrap/install.py
```

The installer creates the stack in `~/.local/state/martinflix-first-run` by default. It starts Sonarr and Radarr, waits for their health checks, reads the keys generated by the apps, and starts the dashboard with private copies of those keys. It checks that the dashboard can read both libraries. Fresh libraries appear empty until you add titles.

The installer prints the dashboard URL and password file path. The default username is `admin`. All three services publish on loopback by default. To give the dashboard a LAN address, pass `--dashboard-bind` with the host's specific IPv4 address. HTTP Basic sends credentials unencrypted across the network. Sonarr and Radarr stay on loopback so their initial setup screens are local.

To run an isolated trial alongside another stack, use a separate state directory and different host ports:

```sh
python3 deploy/bootstrap/install.py \
  --state-dir ~/.local/state/martinflix-trial \
  --dashboard-port 18765 --sonarr-port 18989 --radarr-port 17878
```

Rerun with the same arguments to resume setup. The project name follows the state directory. The installer preserves app configurations and the dashboard password, refreshes the private copies of the Arr keys, and verifies both connections again. Keep the application data and password files outside the checkout. The dashboard has no Docker socket.

This milestone starts Sonarr, Radarr, and dashboard library monitoring. Media storage, download clients, VPN, Prowlarr, Seerr, and Docker status collection are future installer stages. The legacy host deployment has its own Compose files, Docker status collector, and recovery process.
