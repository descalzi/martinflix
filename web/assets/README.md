# Dashboard artwork

MartinFlix masthead and mark generated with the built-in image generation tool and optimized as WebP for the dashboard.

App icons are sourced from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/tree/main/png). The Bookshelf icon comes from the [Bookshelf project](https://github.com/pennydreadful/bookshelf/blob/HEAD/Logo/128.png). The Listenarr icon comes from the [Listenarr project](https://github.com/Listenarrs/Listenarr/blob/canary/.github/logo-icon.png). Images are served locally so clients do not need access to either repository.

## Image generation prompts

**Masthead** — Use case: logo-brand. Wide website masthead for a private home media control room. Large perfectly legible exact text “MartinFlix” in warm ivory editorial serif on left, on right a bold midcentury woodcut illustration of a house silhouette integrating a projector play triangle, subtle concentric projection arcs. Deep forest-black ground #172625, mint and cream lithographic detail, refined and understated. Wide landscape with all artwork inset, no other text or logos, no mockup. High contrast.

**Mark** — Use case: logo-brand. Square app icon for MartinFlix home cinema. Single bold warm ivory house silhouette with a forest-green triangular play cutout, mint accent, midcentury print aesthetic with clean silhouette, on solid deep forest-black #172625. Centered, generous margins, legible at 24 pixels, no lettering, no border, no mockup.
