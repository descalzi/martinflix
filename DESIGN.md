# Design System: MartinFlix

## Overview
A calm home media control room, drawing on the uiux library's Operate mode and humanist product direction. An illustrated MartinFlix masthead uses a home cinema motif. The matching house-and-play mark appears in the navigation and browser tab. Real state remains the focus.

## Colors
Warm paper, dark forest ink, soft green surfaces and restrained green accents. Status indicators use color alongside text.

## Typography
Georgia gives headings an editorial warmth; system sans-serif keeps operational data legible. Small uppercase labels are reserved for navigation and orientation.

## Layout
A compact dark navigation rail frames a generous, responsive working surface. Grouped service cards pair app artwork and roles with Docker status badges and details. Indented branches show services on Gluetun’s network and the BookOrbit database dependency. The library uses a responsive poster grid with title and schedule information; on mobile the navigation moves above the content.

## Components
Use visible keyboard focus, clear text states, labelled controls and responsive layouts. Avoid invented status and claims; show unavailable and incomplete states explicitly.
